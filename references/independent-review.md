# 独立检查：内容判断与实际排版

完成写作者自查和实际结果回读后，如环境允许，交由一名未参与写作的独立检查者只读核验用户指定的文档或范围。只提供必要的任务要求和实际成果，不预设结论，不扩大读取范围，不发送消息或修改文档。

检查者独立判断并给出具体位置和理由：

1. 核心定义、结论、前提和风险是否易于识别；高亮、提示或普通段落是否恰当，有无过度强调。
2. 标题、段落、步骤、并列事项、术语、引用和比较是否反映实际关系；没有合适候选时不强加样式。
3. 用户要求、既有内容、顺序、链接、图片、表格、公式、评论和其他资源是否有证据表明被保留；平台相关检查使用对应工具和实际能力。
4. 实际视觉或交互效果是否看过；未检查的标记为未验证，不把源文件或工具调用成功当作视觉证据。

写作者根据证据修正授权范围内能安全处理的问题并回读受影响部分；需要时请检查者复核。无法调用独立检查者、用户禁止或检查者未实际读取成果时，自己做第二次只读检查，说明“独立检查未完成”及原因；不要把自查冒充独立检查。
